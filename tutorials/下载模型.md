# 下载模型到本地

> 本项目的脚本**只加载本地模型，不会自动下载**。先按本文把模型下好，再去跑练习。
> 这样做的好处：脚本没有隐藏副作用，你知道磁盘上有什么、在哪，换模型也是显式动作。

---

## 一、放哪

推荐放在 **WSL 自己的文件系统**里：

```
~/models/Qwen3-0.6B/
```

**别放 `/mnt/d/...`（也就是 Windows 的 D 盘）。** 原因很实际：

| 位置 | 加载速度 | 备份/可见性 |
|---|---|---|
| `~/models/`（WSL ext4） | **快** | 只在 WSL 里，重建 WSL 会丢 |
| `/mnt/d/models/`（Windows） | 慢（走 9p 协议） | Windows 资源管理器里可见，好备份 |

模型每次加载要读 1.5GB，走 `/mnt/d` 会明显卡。**放 `~/models/`，想要备份再说。**

（WSL 里的 WSL 磁盘其实也能在 Windows 侧访问：在资源管理器地址栏输 `\\wsl$\Ubuntu-24.04\home\miki`。但那是按需访问，不影响读写速度。）

## 二、三步下好

### 1. 进虚拟环境

`huggingface_hub` 装在 venv 里，**必须先激活**：

```bash
source ~/rl-llm/bin/activate
```

忘了这步会报 `ModuleNotFoundError: No module named 'huggingface_hub'`。

### 2. 设国内镜像（建议写进 `.bashrc` 一劳永逸）

```bash
export HF_ENDPOINT=https://hf-mirror.com
```

**必须在下载之前设**，下到一半再设是没用的。

想持久生效：

```bash
echo 'export HF_ENDPOINT=https://hf-mirror.com' >> ~/.bashrc
source ~/.bashrc
```

### 3. 下载

```bash
mkdir -p ~/models

python -c "
from huggingface_hub import snapshot_download
snapshot_download('Qwen/Qwen3-0.6B', local_dir='$HOME/models/Qwen3-0.6B')
"
```

`local_dir` 的作用是**把文件平铺下载到这个目录**，而不是塞进 HF 默认的哈希缓存结构（`~/.cache/huggingface/hub/models--Qwen--Qwen3-0.6B/snapshots/一堆哈希/`）。你指定了 `local_dir`，目录里就是能直接看懂的文件。

## 三、其他下载方式

### 方式 B：命令行工具

```bash
huggingface-cli download Qwen/Qwen3-0.6B --local-dir ~/models/Qwen3-0.6B
```

⚠️ **这个工具的名字在不同版本里改过**（新版本可能叫 `hf`）。如果 `huggingface-cli` 提示找不到命令，试试：

```bash
hf download Qwen/Qwen3-0.6B --local-dir ~/models/Qwen3-0.6B
```

**所以上面那个 Python 写法最保险**，不依赖 CLI 名字。

### 方式 C：网页手动下载

打开模型页面 → Files and versions → 逐个下 `config.json`、`model.safetensors`、`tokenizer.json`、`tokenizer_config.json` 等，再自己放到一个目录里。

**不推荐**——容易漏文件、搞错目录结构，出了问题很难查。除非你的网络环境完全走不通上面两种。

### 备选：魔搭 ModelScope

Qwen 是阿里的模型，**官方同时在魔搭发布**，国内速度通常最稳：

```bash
pip install modelscope
modelscope download --model Qwen/Qwen3-0.6B --local_dir ~/models/Qwen3-0.6B
```

注意：魔搭下载的文件结构和 HF 略有差异，但 `from_pretrained()` 一般能直接读。**真读不了再叫我。**

## 四、确认下好了

```bash
ls -la ~/models/Qwen3-0.6B/
du -sh ~/models/Qwen3-0.6B/
```

**应该看到这些关键文件**（大小合计约 1.5GB）：

| 文件 | 作用 |
|---|---|
| `config.json` | ★ 模型结构声明 —— 你要确认里面有 `Qwen3ForCausalLM` |
| `model.safetensors` | ★ 模型权重，最大的那个文件 |
| `tokenizer.json` / `tokenizer_config.json` | 分词器 |
| `generation_config.json` | 生成相关默认参数 |
| `vocab.json` / `merges.txt` | 词表 |

如果只有几十 MB，说明没下完——重跑一遍下载命令，**已下好的分片会保留，会接着下**（HF 支持断点续传）。

## 五、确认脚本能找到它

`transformers_basics.py` 顶部这一行就是路径：

```python
MODEL = os.path.expanduser("~/models/Qwen3-0.6B")
```

**换模型、换路径，只改这一行。** 脚本启动时会先检查目录在不在，不在就直接报错退出——不会偷偷去下载。

## 六、常见错误对照

| 报错 | 原因 |
|---|---|
| `ModuleNotFoundError: No module named 'huggingface_hub'` | 忘了 `source ~/rl-llm/bin/activate` |
| 下载卡住不动 / 速度几十 KB | 没设 `HF_ENDPOINT` 镜像 |
| `Repository not found` | 仓库名写错，或模型是 gated 需要同意协议 |
| `Can't load tokenizer` | 没下完，或 `local_dir` 下漏了 tokenizer 文件 |
| `OSError: ... does not appear to have a file named config.json` | 路径指错了，或者下的是个空目录 |
